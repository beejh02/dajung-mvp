# 다정 MVP 공유 문서

이 폴더는 구현 코드와 함께 유지하는 MVP 운영/시연용 문서 영역입니다.

## 문서 목록

- [API_SPEC.md](API_SPEC.md): FastAPI 백엔드 API 명세와 인증 정책
- [AGENT_TOOLS.md](AGENT_TOOLS.md): Streamlit AI Agent 도구, demo mode, provider 교체 지점
- [MVP_DEMO.md](MVP_DEMO.md): Phase 10 통합 검증 결과, 데모 시나리오, 시연 전 체크리스트

## 문서 기준

- 문서는 실제 구현 상태를 우선합니다.
- 실제 결제 PG, 실제 RAG, 음성, STT, TTS는 MVP 범위 밖으로 명시합니다.
- API Key, secret, 운영 환경 값은 문서에 기록하지 않습니다.
